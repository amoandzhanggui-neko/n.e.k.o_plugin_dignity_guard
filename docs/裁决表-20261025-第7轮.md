### T10 为什么值得单独说

哈希口径写在**三个地方**：闸的 `HASH_ALGO`、`gate_extra.py` 的 `HASH_ALGO`、`sha16()`/`file_hash16()` 的**实现**。

改一处忘另外两处不会崩，只会静默失效：
- 只改常量不改实现 ⟹ 台账记着"lf"实际算的是 raw ⟹ 判红 7 一片假红
- 改实现不改常量 ⟹ `ledger_files()` 认为口径不符 ⟹ **整份台账被拒用** ⟹ 判红 7 静默退回只看 `git status`

**不崩的失效是最贵的。** 所以 3 条测试里最关键的是第 3 条「同内容不同行尾必须同哈希」——
它验的是**实现**，不是声明。负向验证证明了这一点：

```
删掉归一化后：
  FAILED test_implementation_really_normalizes_line_endings   ← 验实现的，红了
  passed test_both_constants_are_the_expected_value          ← 只验常量的，仍绿
```
