### T4 具体改了什么

| 位置 | 原来 | 现在 |
|---|---|---|
| `_speak` 的通知 | `record("notice_not_delivered")` + warning | 走 `_note_delivery_failure("notice", exc)` |
| `_speak_her_turn` | `record("speech_not_delivered")` + warning（文案是 `could not hand the cue`） | 同上，purpose=`speech` |
| `_push_blocked_notice` | `record("block_notice_not_delivered")` + warning | 同上，purpose=`block_notice` |
| 缺席恢复通知 | `record("away_notice_not_delivered")` + warning | 同上，purpose=`away_notice` |

分级规则：`AttributeError / TypeError / NameError / UnboundLocalError` ⟹
`<purpose>_code_error` + `logger.exception`（带堆栈）；其余 ⟹ `<purpose>_not_delivered` + warning。

**仍然不 re-raise，这是刻意的。** 2026-10-18 实测过：参数名传错 → TypeError →
`Timer 'settings_watch' failed` → 之后整轮静默停摆。让插件"崩掉但活着"比"记错一个名字"更糟。

**故意只收这四个异常。** `KeyError` / `IndexError` 也可能是"宿主返回的结构变了"，
那是**我们没料到**而非**我们写错了**，归到外部故障更诚实。这是取舍，不是定论。

## 二、顺带修掉的 4 个 bug（都是本轮踩出来的）
